In one sentence

This project shows how the "Do chat ao agente" (From chat to agent) course became a 3D stone and wood house that loads in the browser. The course teaches you to move from chat to agents, AI systems that perform tasks on a computer. It has 37 lessons and 23 exercises, with an overview and 4 parts. This guide is for people who create courses or pages and want to see how work like this happens: the requests sent to the AIs, the mistakes, and the measured numbers. You only need a browser to read it. The course is free, but the exercises require a computer and a Claude or ChatGPT subscription. Some use the terminal, the window where you type commands.

How a mistake was caught

  1. One AI delivers the room
    The code runs and the house appears.
  2. Another AI opens the site in a real browser
    The screenshot shows a red ceiling that does not match the wood in the photos.
  3. The problem becomes a request
    The next stage adjusts the ceiling and beam colors.
  4. A new screenshot checks the result
    It shows whether the ceiling now looks closer to the photo. The floor had to be revisited in more than one stage.
How it was built, without jargon

Think of a construction site with a crew, a foreman, and an inspection

An agent is an AI that performs tasks on a computer as well as answering questions. Codex by OpenAI and Claude Code by Anthropic are agents that write and change files. Each had a role here. The independent reviewers were new AI sessions without the builders' notes.

🧱 The crew: Codex

It used the GPT-6.2 Astra AI model at a high effort level, which means it reasoned for longer, through a subscription. It worked in 9 rounds. Each round was a request carried out from start to finish. It generated images of the surfaces and landscape, the text, and the code.

📐 The foreman: Claude Code

It wrote the project description, requests, and tests. It checked the work in a browser and reported anything that failed.

🔍 The inspection: reviewers

They used the course as visitors, without seeing the builders' notes. They gave it a score and listed problems.

The order of work

  1. The request
    Nei from ARCKHÉ asked the team to start from an earlier 3D event, Imersão Jarvis 3D, and recreate a stone and wood house from a set of photos using this course's content.
  2. The course foundation
    Lessons and exercises go into a file shared by the 3D and non-3D versions.
  3. Images, text, and house
    Codex creates the setting and builds the course inside it.
  4. Review and correction
    Screenshots and reviews guide the next rounds.
  5. Final check
    The last round is checked on the published site using a real mouse click and keyboard.

Some mistakes along the way

  1. Red ceiling and burgundy floor
    The colors were adjusted until they looked closer to the photos.
  2. Stone that looked like painted brick, then like a game block
    The wall image was remade from the reference photos.
  3. Test screenshot turned completely black
    The screen was cleared right after it was drawn.
  4. Click caught on the low wall
    People who clicked in the doorway hit the terrace's low wall.
  5. Warning appeared too early
    The notification bar announced arrival at the station while the person was still on the way.

Common questions

Before you enter

Can I build a house like this without programming?

You can do the analysis. Building it requires learning to use agents such as Claude Code or Codex, or getting technical help. This project took 9 rounds, with tests and reviews.

Do I need to program to read it?

No. This guide and the house load in the browser. Some course exercises use the terminal, and the first station teaches you the basics.

Does the course cost anything?

The course is free. The exercises require a computer and a Claude or ChatGPT subscription.

What if the 3D does not load?

There is a non-3D version with the same course and progress.

Does it work on a phone?

The house has touch controls and a non-3D version. Both were tested in a simulation, not on a physical phone. You need a computer to do the exercises.

Did the AI do everything by itself?

No. Nei from ARCKHÉ made the request and approved publication. The AIs worked in 9 rounds, with tests, browser checks, and three independent reviews.

Are the house photos here?

No. They were used only as references and are not on the site or in the repository.
